# 💰 FinTrack — Expense & Budget Tracker

A sleek, single-file expense and budget tracker that logs your income and spending, auto-calculates your balance, and saves everything right in your browser — wrapped in a premium emerald-and-cyan glassmorphism UI.

## ✨ Key Features

- 📊 **Live summary cards** — Balance, total Income, and total Expenses update instantly
- ➕ **Add transactions** with a name, category, amount, and income/expense toggle
- 📋 **Clean history table** with separate columns for Name, Category, and Amount
- 🏷️ **Category pills** and color-coded amounts (green for income, coral for expenses) for fast scanning
- 🗑️ **One-click delete** on any transaction row
- 💾 **Persistent storage** — your data survives refreshes and browser restarts via `localStorage`
- 📱 **Fully responsive** — the table scrolls gracefully on mobile, cards stack on small screens
- 🌌 **Premium glassmorphism design** with an animated gradient background and floating glow blobs

## 🚀 How to Run

It's a single self-contained file — zero installation, zero dependencies.

1. **Download** the `index.html` file from this repo.
2. **Double-click** the file. It will open in your default browser.
3. That's it. Start tracking your money.

> Works offline after the first load (fonts and icons are cached by your browser).

## 🛠️ Technologies Used

- **HTML5** — Semantic structure and a proper data table
- **CSS3** — Glassmorphism, CSS variables for theming, gradient animations, Grid & Flexbox, media queries
- **Vanilla JavaScript** — No frameworks, no build step, no `npm install`
- **localStorage API** — For persistent transaction storage
- **Google Fonts** (Poppins) & **Font Awesome 6** via CDN
